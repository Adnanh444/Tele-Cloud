# Screenshots

The eight images in this folder are **placeholders**. Replace each file with a real screenshot from
the phone, keeping the same name, and the [main README](../../README.md) picks it up automatically.

## Which shot to take

| File | Where to go | What should be visible |
| --- | --- | --- |
| `01-sign-in.png` | Fresh install, first screen | Phone number / QR entry, no personal data |
| `02-channel.png` | Channels screen | The create/choose prompt, one sample channel |
| `03-home.png` | Home / library | A few folders and a thumbnail grid |
| `04-backup.png` | Settings → Backup | Folder selection plus the Wi-Fi/charging switches |
| `05-transfers.png` | Transfers | Some uploads in progress and one completed |
| `06-gallery.png` | Gallery | Photo grid, ideally with a couple of albums |
| `07-restore.png` | Settings → Account → Restore from Telegram | Scope choices and the "N files" summary |
| `08-settings.png` | Settings | Section list, or About with the version number |

## How to take them

1. Fill the app with **harmless content** first — a test channel and a few neutral photos. Never
   publish screenshots with real names, chats, phone numbers or personal photos.
2. Take the screenshot on the phone (`Power + Volume Down`), then crop the status bar away.
3. Resize to **720 px wide** if you can (any width works; 720 keeps the page fast), save as PNG, and
   name it exactly like the table above.
4. Drop the files into this folder and sync.

## Keeping them current

A screenshot that shows a removed feature is worse than no screenshot. When a screen changes
materially, re-take that one image in the same release that changes it.
